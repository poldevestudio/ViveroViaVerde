# Vivero Vía Verde 🌿

Sitio web oficial y catálogo interactivo de **Vivero Vía Verde**, vivero productor de cercos vivos, gramíneas, plantas ornamentales y floración en Escobar / Pilar del Este / Matheu / Zelaya.

## 🚀 Características
- **Página Principal (`index.html`)**: Presentación del vivero, calculadora interactiva de cercos vivos, valoraciones de clientes en Google Maps, horarios dinámicos y acceso directo a WhatsApp.
- **Página de Producción (`produccion.html`)**: Métricas de cultivo, ciclo de producción en 4 etapas, historias de invernadero y catálogo completo filtrable con vista rápida modal.
- **Diseño Responsive & Moderno**: Paleta botánica cuidada, barra de navegación fija con menú desplegable de WhatsApp y optimización para dispositivos móviles.

## 📍 Ubicación
Calle Domingo Nazarre entre Matheu y Zelaya, Zona Norte, Buenos Aires.
